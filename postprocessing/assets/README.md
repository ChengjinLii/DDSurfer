# Surface Atlas Data

[Postprocessing](../README.md) | [Build guide](../core/README.md) | [中文](README.zh-CN.md)

`atlas.tar.gz` contains atlas meshes, cortex labels, annotations, the folding
reference, color table and license notices. **It contains no native executables.**
The local builder verifies it against `manifest.json` before installing the data.

Original data bytes and notices are preserved. These resources retain the
[FreeSurfer license](LICENSE.txt) and included third-party notices, not DDSurfer's
MIT license. No private activation key is included.
