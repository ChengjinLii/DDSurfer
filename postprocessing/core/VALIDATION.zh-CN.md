## 构建验证

于 **2026-10-23** 在 Linux x86_64／Ubuntu 22.04、GCC 11.4、CMake 3.31.6 上验证。
实际运行 Python 构建命令，从固定源码版本
`7eb846079b0dc0c92e8313205a3d2387b5c7a354` 编译了七个原始 FreeSurfer 命令，
ITK Common／VNL 4.13.2 和 zlib 1.3.1 也来自经过校验的源码包。
对 ITK 编译器识别条件加入了兼容新 GCC 的修正，未重写数值计算函数。

编译时通过挂载隔离隐藏了完整 FreeSurfer 安装及之前的预编译组件实验目录，
没有向构建过程提供 FreeSurfer 激活文件。生成的七个命令均通过 `--version` 启动检查，
完成安装清单和文件校验后才原子发布；不是从已有安装复制可执行文件。

随项目提供的图谱压缩包**只有数据和许可声明**，没有 `bin/` 目录及私人激活文件。
当前实现不分发预编译的原生命令包。

## 数值对照

采用 **HCP 100307 左半球**，包含 164,239 个顶点和 328,474 个三角面。
两组均从同一份原生 scanner RAS 白质／软脑膜 OBJ 独立运行，使用仅含几何信息的
LIA 参考体积、4 线程、球面随机种子 1234，以及 `aparc,aparc.a2009s` 两套图谱。

- **参照组：**已有的 FreeSurfer 7.4.1 安装。
- **实验组：**本机从源码编译的组件，不是提取的发行版二进制。
- **隔离条件：**实验组运行时隐藏了参照安装、旧二进制实验及构建目录。
  仅依赖已编译命令、已安装图谱、Python 环境及单独提供的激活文件。

**检查的 139 项文件内容，其数值及结构全部一致**，比较时没有放宽浮点容差：

| 输出 | 结果 |
| --- | --- |
| 白质／软脑膜、orig、smoothwm、膨胀表面、球面及配准后球面 | 解码后的顶点、三角面和体积几何一致 |
| 面积、曲率、沟深及厚度 | 标量逐值一致，最大差值为 0 |
| 皮层掩膜 | 顶点归属及标签行一致 |
| `aparc`、`aparc.a2009s` | 顶点标签一致率 100%，颜色表及脑区名称一致 |
| 脑区标签和统计 | 行内容及数值一致 |
| fsaverage 标量数据 | 数据、affine 及 MGH 数值头信息一致 |

皮层文件头中的路径／时间文本不要求逐字节相同。上游版本信息函数包含编译时间，
因此不同次编译的可执行文件哈希也可能不同。文件字节一致、数值一致和解剖准确性是不同问题。
这里以 FreeSurfer 输出作为兼容性参照，**不是以其作为人工解剖真值**。

## 测试与边界

CPU 测试共 **187 项，全部通过**，覆盖后端选择、原 FreeSurfer 用法兼容、
显式构建及禁止隐式联网、依赖校验、安全解压、源码改动检测、组件完整性、
私人激活文件排除、参数透传及空间几何。

本地证据保存在 `outputs/source-build-check/` 下，不加入版本控制：
`build-command.log`、`build-command-final.log`、`work/` 中的源码与构建日志、
`native-files.trace`、`source-comparison.json`、两组完整输出及 `tests-final.log`。
本地安装清单记录实际受测二进制的校验和及编译工具链。

**尚未完成：**原生 Windows 支持、macOS 编译、跨平台数值一致性、多数据集队列，
以及右半球源码构建结果对照。不能从 Linux 测试推断这些项目已通过。
用户仍可选择已有的平台原生 FreeSurfer 安装，不必使用本机源码构建路线。
没有宣称计算速度提高；原数值算法和迭代参数保留，首次编译会增加准备成本。
